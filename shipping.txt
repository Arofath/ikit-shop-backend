ជំហានទី ១៖ គណនាថ្លៃដឹកជញ្ជូនគោល (Base Shipping Cost)ប្រព័ន្ធនឹងទៅទាញយកទិន្នន័យពីតារាង shipping_zones ផ្អែកលើទីតាំងដែលភ្ញៀវបានរើស រួចយកមកផ្ទៀងផ្ទាត់ជាមួយទំហំទឹកប្រាក់ដែលភ្ញៀវទិញ (Subtotal)។
    - លក្ខខណ្ឌទី ១ (ទិញមិនដល់ការកំណត់)៖ បើទឹកប្រាក់សរុប (Subtotal) តូចជាង free_shipping_threshold នោះ base_shipping_cost គឺស្មើនឹងតម្លៃពេញ (ឧ. $1.50)។
    - លក្ខខណ្ឌទី ២ (ទិញដល់ការកំណត់)៖ បើទឹកប្រាក់សរុប (Subtotal) ធំជាង ឬស្មើ free_shipping_threshold នោះកូដនឹងប្តូរ base_shipping_cost ទៅជា $0.00 ដោយស្វ័យប្រវត្តិ។
    - លក្ខខណ្ឌទី ៣ (អត់មានប្រូម៉ូសិនហ្វ្រី)៖ បើសិនជា Admin មិនបានកំណត់ free_shipping_threshold ទេ (មានន័យថាវា Null) នោះ base_shipping_cost គឺយកតម្លៃពេញជានិច្ច មិនថាទិញច្រើនប៉ុណ្ណាក៏ដោយ (ជាទូទៅប្រើសម្រាប់ដឹកទៅខេត្ត)។

ជំហានទី ២៖ គណនាថ្លៃទំនិញធំៗ (Bulky Surcharge Total)ប្រព័ន្ធនឹងធ្វើការខ្វែង (Loop) ទៅលើទំនិញនីមួយៗនៅក្នុងកន្ត្រក (Cart) របស់ភ្ញៀវ ដើម្បីឆែកមើលជួរឈរ shipping_surcharge ពីតារាង products។
    - រូបមន្ត៖ Bulky Surcharge Total = សរុបនៃ (តម្លៃ Surcharge របស់ទំនិញ * ចំនួនដែលទិញ QTY)
    - ឧទាហរណ៍៖ ភ្ញៀវទិញ Mouse ចំនួន ៣ (Surcharge $0) និង PC Case ចំនួន ២ (Surcharge $2.00)។ ប្រព័ន្ធនឹងគណនា៖ $(0 \times 3) + (2.00 \times 2) = \$4.00$។ ដូច្នេះ bulky_surcharge_total គឺ $4.00។
    
ជំហានទី ៣៖ សរុបថ្លៃដឹកជញ្ជូនចុងក្រោយ (Total Shipping Fee)នៅជំហានចុងក្រោយ ប្រព័ន្ធគ្រាន់តែយកលទ្ធផលពីជំហានទី ១ និងទី ២ មកបូកបញ្ចូលគ្នា ដើម្បីរកថ្លៃដឹកសរុបដែលភ្ញៀវត្រូវបង់។
    - រូបមន្ត៖ Total Shipping Fee = Base Shipping Cost + Bulky Surcharge Total📊 
    - ឧទាហរណ៍សាកល្បងជាមួយនឹងកូដ (Dry Run)សន្មតថា Zone ភ្នំពេញ៖ Base Cost = $1.50, Threshold = $100.00
        - សេណារីយ៉ូ ក (ភ្ញៀវទិញរបស់តូច តម្លៃ $40):ជំហាន ១៖ Subtotal $40 < $100 ដូច្នេះ Base = $1.50ជំហាន ២៖ គ្មានរបស់ធំ ដូច្នេះ Surcharge = $0.00ជំហាន ៣៖ $1.50 + $0.00 = $1.50 (ថ្លៃដឹកសរុប)
        - សេណារីយ៉ូ ខ (ភ្ញៀវទិញរបស់តូច តម្លៃ $150):ជំហាន ១៖ Subtotal $150 >= $100 ដូច្នេះ Base = $0.00 (Free)ជំហាន ២៖ គ្មានរបស់ធំ ដូច្នេះ Surcharge = $0.00ជំហាន ៣៖ $0.00 + $0.00 = $0.00 (ដឹកហ្វ្រី)សេណារីយ៉ូ គ (ភ្ញៀវទិញ Monitor ចំនួន ២ តម្លៃសរុប $300, Surcharge មួយតម្លៃ $2):ជំហាន ១៖ Subtotal $300 >= $100 ដូច្នេះ Base = $0.00 (Free)ជំហាន ២៖ ទិញ ២ គុណនឹង $2 ដូច្នេះ Surcharge = $4.00ជំហាន ៣៖ $0.00 + $4.00 = $4.00 (ថ្លៃដឹកសរុប) (ប្រព័ន្ធហ្វ្រីថ្លៃដឹកគោល ប៉ុន្តែគិតតែថ្លៃសេវាអីវ៉ាន់ធំ ៤ដុល្លារ)។
